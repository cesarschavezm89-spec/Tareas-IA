# Juego Nim con Minimax

Aplicacion de escritorio en Java Swing para jugar Nim contra una computadora
que elige sus movimientos con el algoritmo Minimax.

## Requisitos

- JDK instalado y disponible en `PATH`.

## Ejecutar

Desde esta carpeta, compila y ejecuta la aplicacion:

```powershell
javac -d bin src\*.java
java -cp bin Main
```

Tambien puedes abrir esta carpeta en Visual Studio Code y ejecutar `Main.java`.
